Spike: Twelve Data im Browser

Wegwerf-Testseite, nicht Teil der App. Ruft Tageskurse direkt aus dem Browser ab, ohne Server und ohne Proxy. Der Key wird als Header gesendet, nie in der URL.

API-Key

Ohne Haken bleibt der Key nur im Speicher dieser Seite. Mit Haken liegt er unverschlüsselt im localStorage dieser Domain.

Abfrage

Ein Symbol pro Zeile, optional mit Parametern, z. B. MUV2 exchange=XETR oder MUV2 mic_code=XETR.

Symbolsuche

Zeigt, an welchen Börsen ein Symbol existiert und welcher Plan nötig ist.
